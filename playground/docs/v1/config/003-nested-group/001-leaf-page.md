A plain page inside a group. Its sidebar label starts with a letter, so
`SidebarDefaultEmoji.vue` tags it `default-emoji-file` and `base.css` draws the
4px dot in front of it.

Depth does not change the marker: a leaf is a leaf at any nesting level.
